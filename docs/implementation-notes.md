# ملاحظات التنفيذ

- التطبيق يستهدف Frappe v15/v16 ويستخدم DocTypes قياسية؛ راجع حقول `options` قبل الترحيل إلى إصدار محدد.
- PostgreSQL مذكور في المتطلبات الوظيفية، لكن Frappe القياسي يعتمد MariaDB في الإصدارات الشائعة؛ يلزم اعتماد مصفوفة التوافق قبل الإنتاج.
- يجب إضافة SSO، النسخ الاحتياطي، سياسات الاحتفاظ، وسجل تدقيق مؤسسي قبل التشغيل الفعلي.
- استعلامات التحليل موجودة في `academic_management/api/dashboard.py` ويمكن تحويلها إلى Query Reports أو Charts.
